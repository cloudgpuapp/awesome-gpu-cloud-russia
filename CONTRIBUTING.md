# Как добавить сервис / Contributing

Спасибо за вклад. Правила, чтобы список оставался честным:

1. Откройте PR, добавив строку в нужную таблицу README.md в формате: `Сервис | Что есть | Тарификация | Оплата из РФ | Ссылка`.
2. Каждый факт подтверждайте ссылкой на страницу самого провайдера (тарифы, оплата, документация). В описании PR перечислите источники.
3. Цену указывайте только если она есть на странице провайдера. Формат: «по данным сайта на <месяц год>» плюс ссылка. Не пишите цены из обзоров и форумов.
4. Если не можете проверить (например, оплату из РФ), пишите «не проверено».
5. Без оценочных формулировок и критики конкурентов: только факты.
6. Сервисы, которые вы сами делаете, помечайте «(сервис автора PR)» / раскрывайте интерес.
7. Проверьте, что ссылки отвечают кодом 200/301/302: `curl -sIL -o /dev/null -w "%{http_code}" <url>`.
8. Обновите дату «Последнее обновление» в README.md.

Запросы на удаление от самих провайдеров (неактуально или неверно) рассматриваются с источником.

English: open a PR adding a row to the right table; link every claim to the provider's own page; state a price only if it is on their page (with month/year); write «не проверено» for anything unverified; disclose affiliation; keep neutral; verify links return 200/301/302.
